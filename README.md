# Data-Analysis-Dashboard
 Excel-based dashboard delivering structured analysis of Vrinda Store’s sales and customer data. Provides clear insights on sales vs orders, gender-wise performance, order status, top products, age-gender trends, and channel effectiveness to support informed, data-driven decisions.
